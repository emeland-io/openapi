# Node

Represents a node in the EmELand model. A node is an instance of a node type and represents a specific entity within the landscape.

- **Type:** object

## Properties

- `annotations` (array of [Annotation](./Annotation.md)) — A set of key-value pairs for storing additional metadata about the node.
- `description` (string) — A human-readable description of the node.
- `displayName` (string, required) — The human-readable name of the node.
- `nodeId` (string (uuid), required) — An UUID that uniquely identifies the node. It should be generated and assigned when the node is created and must remain constant throughout the node's lifecycle. The field is optional in some contexts, such as when creating a new node where the ID may be generated by the system itself.
- `nodeType` (string (uuid), required) — The UUID of the node type that this node is an instance of.
