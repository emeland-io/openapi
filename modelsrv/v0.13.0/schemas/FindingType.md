# FindingType

Represents a type of findings in the EmELand model. A finding type defines the type of rule violation and provides metadata about the rule. They are defined by the original source of a finding, e.g., a data collector or a compliance standard. Use the FindingType of a Finding to ensure any further processing or filtering is only applied to findings that are actually understood by the filter.

- **Type:** object

## Properties

- `annotations` (array of [Annotation](./Annotation.md)) — A set of key-value pairs for storing additional metadata about the finding class.
- `description` (string) — A brief description of the finding class's purpose and scope.
- `displayName` (string) — The human-readable name of the finding class.
- `findingTypeId` (string (uuid)) — An UUID that uniquely identifies the finding class. It should be generated and assigned when the finding class is created and must remain constant throughout the finding class's lifecycle. The field is optional in some contexts, such as when creating a new finding class where the ID may be generated by the system itself.
