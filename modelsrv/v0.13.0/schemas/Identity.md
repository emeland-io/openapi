# Identity

Represents an identity in the EmELand model. An identity can represent a person, a service account, or any other identifiable entity that can be associated with access rights and permissions within the landscape.

- **Type:** object

## Properties

- `annotations` (array of [Annotation](./Annotation.md)) — A set of key-value pairs for storing additional metadata about the identity.
- `description` (string) — A brief description of the identity's purpose and characteristics.
- `displayName` (string, required) — The human-readable name of the identity.
- `identityId` (string (uuid), required) — An UUID that uniquely identifies the identity. It should be generated and assigned when the identity is created and must remain constant throughout the identity's lifecycle. The field is optional in some contexts, such as when creating a new identity where the ID may be generated by the system itself.
