# Parameter

A parameter defines an identifier for a grouping of discrete ValidValues.

- **Type:** object

## Properties

- `annotations` (array of [Annotation](./Annotation.md)) — A set of key-value pairs for storing additional metadata about the parameter.
- `displayName` (string, required) — The human-readable name of the parameter.
- `parameterId` (string (uuid), required) — An UUID that uniquely identifies the parameter.
