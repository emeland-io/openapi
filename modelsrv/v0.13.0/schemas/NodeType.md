# NodeType

Represents a type of node in the EmELand model. A node type defines the characteristics and capabilities of nodes that belong to this type.

- **Type:** object

## Properties

- `annotations` (array of [Annotation](./Annotation.md)) — A set of key-value pairs for storing additional metadata about the node type.
- `description` (string) — A brief description of the node type's purpose and characteristics.
- `displayName` (string, required) — The human-readable name of the node type.
- `nodeTypeId` (string (uuid), required) — An UUID that uniquely identifies the node type. It should be generated and assigned when the node type is created and must remain constant throughout the node type's lifecycle. The field is optional in some contexts, such as when creating a new node type where the ID may be generated by the system itself.
