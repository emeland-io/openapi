# OrgUnit

Represents a organizational unit in the EmELand model. This can be used to represent departments, teams, or any other organizational structure relevant to the landscape.

- **Type:** object

## Properties

- `annotations` (array of [Annotation](./Annotation.md)) — A set of key-value pairs for storing additional metadata about the organizational unit.
- `description` (string) — A brief description of the organizational unit's purpose and characteristics.
- `displayName` (string, required) — The human-readable name of the organizational unit.
- `orgUnitId` (string (uuid), required) — An UUID that uniquely identifies the organizational unit. It should be generated and assigned when the organizational unit is created and must remain constant throughout the organizational unit's lifecycle. The field is optional in some contexts, such as when creating a new organizational unit where the ID may be generated by the system itself.
