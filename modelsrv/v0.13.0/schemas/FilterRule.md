# FilterRule

Documents a filter registered in a modelsrv instance. Filter rules describe how change events may be passed through, suppressed, or expanded by the event filter chain.

- **Type:** object

## Properties

- `description` (string) — A brief description of what the filter rule does.
- `displayName` (string, required) — The human-readable name of the filter rule.
- `ruleId` (string (uuid), required) — An UUID that uniquely identifies the filter rule.
