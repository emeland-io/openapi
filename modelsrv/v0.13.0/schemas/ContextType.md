# ContextType

Represents a type of context in the EmELand model. A context type defines the characteristics and categorization of contexts.

- **Type:** object

## Properties

- `annotations` (array of [Annotation](./Annotation.md)) — A set of key-value pairs for storing additional metadata about the context type.
- `contextTypeId` (string (uuid), required) — An UUID that uniquely identifies the context type. It should be generated and assigned when the context type is created and must remain constant throughout the context type's lifecycle. The field is optional in some contexts, such as when creating a new context type where the ID may be generated by the system itself.
- `description` (string) — A brief description of the context type's purpose and scope.
- `displayName` (string, required) — The human-readable name of the context type.
