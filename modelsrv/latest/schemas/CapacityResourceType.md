# CapacityResourceType

Shared vocabulary for a measurable capacity limit with a unit.

- **Type:** object

## Properties

- `annotations` (array of [Annotation](./Annotation.md))
- `capacityResourceTypeId` (string (uuid), required)
- `description` (string)
- `displayName` (string, required)
- `unit` (string, required) — Default measurement unit for amounts of this type (e.g. cores, GiB).
