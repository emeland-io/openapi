# Group

Represents a group of identities in the EmELand model.

- **Type:** object

## Properties

- `annotations` (array of [Annotation](./Annotation.md)) — A set of key-value pairs for storing additional metadata about the group.
- `description` (string) — A brief description of the group's purpose and characteristics.
- `displayName` (string, required) — The human-readable name of the group.
- `groupId` (string (uuid), required) — An UUID that uniquely identifies the group. It should be generated and assigned when the group is created and must remain constant throughout the group's lifecycle. The field is optional in some contexts, such as when creating a new group where the ID may be generated by the system itself.
