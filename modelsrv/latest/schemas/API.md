# API

- **Type:** object

## Properties

- `annotations` (array of [Annotation](./Annotation.md)) — A set of key-value pairs for storing additional metadata about the API instance.
- `apiId` (string (uuid)) — An UUID that uniquely identifies the API. It should be generated and assigned when the API is created and must remain constant throughout the API's lifecycle. The field is optional in some contexts, such as when creating a new API where the ID may be generated by the system itself.
- `description` (string) — A brief description of the API's purpose and functionality.
- `displayName` (string, required) — The human-readable name of the API.
- `system` (string (uuid)) — The UUID of the system that provides this API.
- `type` (required) — The type of the API (e.g., OpenAPI, gRPC, GraphQL). If the type is unknown, it should be set to "Unknown". If the type does not fit any predefined categories, it should be set to "Other". In such cases, additional details about the API type should be provided in the description field. Enum: `Unknown`, `OpenAPI`, `GraphQL`, `gRPC`, `Other`.
- `version` ([Version](./Version.md)) — Version information for all objects in the EmELand model.
